# Architecture Context

## Stack

**Framework**

- Next.js 14 (App Router)

**Langauge**

- TypeScript
- Tailwind

**UI**

- Tailwind CSS
- shadcn/ui

**API INTEGRATION**

- Stand by for API design implement later

## Engineering rule

1. Use production-grade architecture
2. Follow scalable frontend structure
3. Use reusable components
4. Keep components small and modular
5. Separate UI and business logic
6. Use strong typing everywhere
7. Avoid duplicated logic
8. Optimize rendering performance
9. Apply accessibility best practices
10. Apply frontend security best practices

## Performance role

1. Avoid unnecessary re-renders
2. Use memoization properly
3. Lazy load heavy components
4. Use dynamic imports
5. Optimize bundle size
6. Optimize images
7. Use streaming/Suspense where appropriate
8. Cache API requests correctly
9. Virtualize large lists
10. Avoid blocking rendering

## Security Rule

1. Never expose secrets
2. Prevent XSS
3. Sanitize user input
4. Secure token handling
5. Use HttpOnly cookies when possible
6. Prevent sensitive data leakage
7. Validate client input
8. Avoid unsafe HTML rendering
