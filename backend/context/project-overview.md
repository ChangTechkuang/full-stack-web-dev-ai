# Overview

The system demonstrates a complete modern web application architecture using AI-assisted development workflows with Claude Code.

## Project Name

TaskFlow (internal Work Request management

## Project Type

Web App

## Your Role

- Backend architect

- Senior Spring Boot engineer

- Database architect

- Performance engineer

- Security reviewer

- API architect

## Goals

Employees can:

- Submit work requests

- Track request status

- View assigned tasks

Managers can:

- Review incoming requests

- Change request statuses

- Manage workflow progression

The project is intended for:

- Internal developer training

- AI-assisted development demonstrations

- Full-stack architecture showcase

- Parallel frontend/backend development workflows

## Features

**Authentication**

- JWT authentication

- Role-based authorization (EMPLOYEE / MANAGER)

- Route protection

**Work Request Management**

- Create work requests

- Update request details

- View request list

- View request detail

- Delete requests

**Workflow Status Management**

Supported statuses:

- PENDING

- IN_PROGRESS

- DONE

- REJECTED

**Filtering & Search**

- Filter by priority

- Filter by status

- Filter by assignee
